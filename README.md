# MindMate — Student Wellness App

MindMate is a responsive student wellness UI/UX concept built as an interactive website prototype with HTML, CSS, and JavaScript. It explores how a calm, approachable interface can make everyday mood check-ins and healthy routines feel simple.

## Prototype

Open [`index.html`](index.html) in a browser. The prototype works locally and does not require a build step or backend.

## Included screens and interactions

- **Home dashboard:** welcome view, daily mood prompt, weekly overview, and habit checklist.
- **Mood tracker:** choose a mood and view an illustrative seven-day history.
- **Healthy habits:** check off four small wellbeing activities; the progress indicator updates immediately.
- **Wellness resources:** practical breathing, reflection, and reaching-out prompts.
- **Profile:** a sample student profile and reminder settings.
- Responsive navigation and layouts for desktop, tablet, and mobile screens.

## Design direction

Soft purple and pastel colors, rounded cards, clear typography, and small friendly illustrations create a calm visual tone. The interface keeps key actions visible and uses short, supportive copy to make each screen easy to scan.

## Notes

This is a student design concept and interaction demo, not a medical service. The mood history is illustrative. Check-ins and checklist state are handled in the browser and are not sent to a service.
